# Gemma4 画像認識Webアプリ - シーケンス図

## 1. 画像アップロード認識

```
ユーザー          React UI           Next.js API        Ollama          gemma4
  │                │                    │                 │               │
  │ 画像ファイル選択 │                    │                 │               │
  │────────────────>│                    │                 │               │
  │                │ ファイルをbase64化   │                 │               │
  │                │────────────┐        │                 │               │
  │                │            │        │                 │               │
  │                │<───────────┘        │                 │               │
  │                │ selectedImageに格納  │                 │               │
  │                │                    │                 │               │
  │ 「認識する」クリック│                    │                 │               │
  │────────────────>│                    │                 │               │
  │                │ POST /api/vision/analyze               │               │
  │                │ {imageBase64, mode}│                 │               │
  │                │────────────────────>│                 │               │
  │                │                    │ POST /api/generate               │
  │                │                    │────────────────>│               │
  │                │                    │                 │ 画像認識リクエスト │
  │                │                    │                 │───────────────>│
  │                │                    │                 │               │
  │                │                    │                 │<──────────────│
  │                │                    │                 │ 認識結果        │
  │                │                    │<────────────────│               │
  │                │                    │ {response: "..."}│               │
  │                │<────────────────────│                 │               │
  │                │ {result: "..."}     │                 │               │
  │                │ analyzeResultに格納  │                 │               │
  │<───────────────│                    │                 │               │
  │ 認識結果表示     │                    │                 │               │
```

## 2. カメラ撮影認識

```
ユーザー          React UI           カメラ            Next.js API      Ollama
  │                │                  │                  │               │
  │ 「カメラ起動」クリック│                  │                  │               │
  │────────────────>│                  │                  │               │
  │                │ getUserMedia()    │                  │               │
  │                │──────────────────>│                  │               │
  │                │                  │ 映像ストリーム返却  │               │
  │                │<──────────────────│                  │               │
  │                │ videoタグにセット   │                  │               │
  │                │ OCRループ開始       │                  │               │
  │                │                  │                  │               │
  │ 「撮影して認識」クリック│               │                  │               │
  │────────────────>│                  │                  │               │
  │                │ canvasに現在フレーム描画               │               │
  │                │────────────┐      │                  │               │
  │                │<───────────┘      │                  │               │
  │                │ base64化          │                  │               │
  │                │ POST /api/vision/analyze               │               │
  │                │──────────────────────────────────────>│               │
  │                │                  │                  │ POST /api/generate
  │                │                  │                  │───────────────>│
  │                │                  │                  │<──────────────│
  │                │<──────────────────────────────────────│               │
  │                │ analyzeResultに格納│                  │               │
  │<───────────────│                  │                  │               │
  │ 認識結果表示     │                  │                  │               │
```

## 3. リアルタイムOCRループ

```
React UI (setInterval 2秒)        Next.js API        Ollama
  │                                    │               │
  │ [カメラ起動時にループ開始]            │               │
  │                                    │               │
  │ canvasに現在フレーム描画              │               │
  │────────────┐                        │               │
  │<───────────┘                        │               │
  │ base64化（640px, quality 0.7）       │               │
  │                                    │               │
  │ isRealtimeOcrRunning === false のみ送信               │
  │ POST /api/vision/ocr               │               │
  │────────────────────────────────────>│               │
  │ isRealtimeOcrRunning = true         │               │
  │                                    │ POST /api/generate (OCRプロンプト)
  │                                    │───────────────>│
  │                                    │<──────────────│
  │<────────────────────────────────────│               │
  │ {text: "認識文字"}                  │               │
  │ isRealtimeOcrRunning = false        │               │
  │                                    │               │
  │ 前回テキストと比較                   │               │
  │ 異なる場合のみ realtimeText 更新      │               │
  │                                    │               │
  │ [2秒後に次のループ]                  │               │
  │                                    │               │
  │ [カメラ停止時にループ終了]            │               │
```

## 4. エラーハンドリングフロー

```
React UI              Next.js API         Ollama
  │                       │                 │
  │ POST /api/vision/*    │                 │
  │───────────────────────>│                 │
  │                       │ POST /api/generate
  │                       │─────────────────>│
  │                       │                 │
  │                       │  [Ollama未起動の場合]
  │                       │  fetch失敗 (ECONNREFUSED)
  │                       │────────────┐    │
  │                       │<───────────┘    │
  │                       │ error判定        │
  │                       │ 500 {error: "Ollamaが起動していません..."}
  │<───────────────────────│                 │
  │ errorMessageにセット   │                 │
  │ ステータス表示          │                 │
```

# Local LLM Vision - UI設計

## 画面構成

画面上部の **モード切替タブ** で「通常認識」「名刺読み取り」を切り替える。video 要素は常に同一 DOM ノードを使い回し、`ref` 安定性を保つ。

### 共通領域

```
┌──────────────────────────────────────────────┐
│  Local LLM Vision                            │
├──────────────────────────────────────────────┤
│  [通常認識] [名刺読み取り]    ← モード切替タブ   │
│                                              │
│  [カメラ起動 / カメラ停止]                       │
│                                              │
│  ステータス: 認識中... / エラーメッセージ         │
│                                              │
└──────────────────────────────────────────────┘
```

### 通常認識モード

```
┌──────────────────────────────────────────────┐
│  [カメラ起動 / 停止]                            │
│                                              │
│  ┌──────────────────────────────────────┐   │
│  │ カメラ映像 (video)                     │   │
│  └──────────────────────────────────────┘   │
│                                              │
│  [撮影して認識]   ※カメラ起動中のみ              │
│                                              │
│  ─────── リアルタイム文字認識 ───────────────  │
│  ┌──────────────────────────────────────┐   │
│  │ 2秒ごとに更新されるOCR結果              │   │
│  └──────────────────────────────────────┘   │
│                                              │
│  ─────── 画像認識結果 ───────────────────────  │
│  ┌──────────────────────────────────────┐   │
│  │ Gemma4 の詳細な分析結果                │   │
│  └──────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

### 名刺読み取りモード

PC では映像と結果パネルを横並び、モバイルでは縦積み。

```
┌──────────────────────────────────────────────┐
│  ┌────────────────────┐  ┌──────────────┐   │
│  │ カメラ映像 (video)   │  │ 名刺読み取り  │   │
│  │  [スキャン中…]      │  │ 結果パネル   │   │
│  │                    │  │              │   │
│  │                    │  │ 各フィールド   │   │
│  │                    │  │ を編集可能    │   │
│  │                    │  │ (input/      │   │
│  │                    │  │  textarea)   │   │
│  │                    │  │              │   │
│  │                    │  │ [破棄][保存] │   │
│  └────────────────────┘  └──────────────┘   │
│                                              │
│  [今すぐ読み取る]   ※カメラ起動中のみ            │
│                                              │
│  ─────── 保存済み名刺 (N件) ─── [CSV ダウンロード] ─  │
│  ┌──────────────────────────────────────┐   │
│  │ 1. 山田 太郎 (ヤマダ タロウ)           │   │
│  │    株式会社A / 営業部 / 部長          │   │
│  │    090-0000-0001            [編集][削除] │
│  │ ─────────────────────────────────  │   │
│  │ 2. 佐藤 花子                         │   │
│  │    株式会社B / 開発部                 │   │
│  │    090-0000-0002            [編集][削除] │
│  └──────────────────────────────────────┘   │
│  ※ 離脱すると保存データは消えます              │
└──────────────────────────────────────────────┘
```

編集モードでは行が展開して全フィールドの編集フォーム + [キャンセル][変更を保存] が出る。

## UI 項目一覧

### 共通

| 項目 | 種別 | 表示条件 | 説明 |
|---|---|---|---|
| モード切替タブ | `<button>` × 2 | 常時 | 「通常認識」「名刺読み取り」を切替 |
| カメラ起動 / 停止ボタン | `<button>` | 常時 | カメラを起動・停止 |
| ステータス表示 | `<p>` | 認識中 / 一時通知 | 黄色の点滅テキスト |
| エラー表示 | `<div>` | エラー時 | 赤背景のメッセージボックス |
| カメラ映像 | `<video autoplay playsInline muted>` | カメラ起動中 | 同一 DOM を維持。継続オートフォーカス使用（対応端末のみ） |

### 通常認識モード

| 項目 | 種別 | 表示条件 | 説明 |
|---|---|---|---|
| 撮影して認識ボタン | `<button>` | カメラ起動中 | 現フレームを 1024px / 0.8 で取得し送信 |
| リアルタイム OCR 欄 | `<div>` | カメラ起動中 | 2 秒ごとに更新される文字 |
| 画像認識結果欄 | `<div>` | 認識完了後 | gemma4 の詳細応答 |

### 名刺読み取りモード

| 項目 | 種別 | 表示条件 | 説明 |
|---|---|---|---|
| スキャンインジケータ | `<span>` | カメラ起動中 | 「スキャン中…」「自動スキャン待機中」 |
| 今すぐ読み取るボタン | `<button>` | カメラ起動中 | 自動スキャンと並行して即時 1 回スキャン |
| 名刺結果パネル | `<div>` | 名刺モード | 12 フィールドの編集 input/textarea + [破棄][保存] |
| 保存済みリスト | `<ul>` | 名刺モード | 1 件ずつサマリ表示。`[編集][削除]` ボタン |
| 編集モードフォーム | `<div>` | 編集中の行 | 結果パネルと同じ `CardFieldsEditor` を内側に展開 |
| CSV ダウンロードボタン | `<button>` | 名刺モード | 0 件でもヘッダーのみの CSV を出力 |

## 状態管理 (React State / Ref)

| 状態名 | 型 | 初期値 | 説明 |
|---|---|---|---|
| `appMode` | `'general' \| 'card'` | `'general'` | 現在のモード |
| `selectedImage` | `string \| null` | `null` | アップロード画像の base64（ハンドラ存在、現在 UI 未配置） |
| `cameraStream` | `MediaStream \| null` | `null` | カメラ映像ストリーム |
| `analyzeResult` | `string` | `''` | 通常モードの認識結果 |
| `realtimeText` | `string` | `''` | 通常モードのリアルタイム OCR 結果 |
| `cardData` | `BusinessCardData \| null` | `null` | 名刺モードの現在編集中スキャン結果 |
| `savedCards` | `SavedCard[]` | `[]` | 保存済み名刺リスト |
| `editingSavedCardId` | `string \| null` | `null` | 編集対象の保存済み名刺 id |
| `editingDraft` | `BusinessCardData \| null` | `null` | 編集中ドラフト（保存で確定、キャンセルで破棄） |
| `isAnalyzing` | `boolean` | `false` | 通常認識中フラグ（手動撮影） |
| `isAutoScanning` | `boolean` | `false` | 名刺自動スキャン中フラグ（インジケータ用） |
| `errorMessage` | `string` | `''` | エラーメッセージ |
| `statusMessage` | `string` | `''` | 認識中 / 一時通知 |
| `hasCardDataRef` (ref) | `boolean` | `false` | `cardData !== null` を ref で同期し、ループ closure から最新値を見る |

## ボタンの活性 / 非活性ルール

| ボタン | 非活性条件 |
|---|---|
| カメラ起動 | `isAnalyzing === true` |
| 撮影して認識 / 今すぐ読み取る | `isAnalyzing === true` |
| 結果パネル「リストに保存」 | `cardData === null` または全フィールド空 |
| 保存済み行「編集 / 削除」 | 他の行が編集中 (`editingSavedCardId !== null`) |
| 編集モード「変更を保存」 | ドラフトが全フィールド空 |
| CSV ダウンロード | 常時活性（0 件でもヘッダーのみで出力） |

## 自動スキャン / OCR ループの表示ルール

- **通常モード OCR**: 2 秒間隔・640px / 0.7。前回結果と同一文字列なら state を更新しない（チラつき防止）
- **名刺モード**: 3 秒間隔・800px / 0.85。`cardData` が非 null の間は新規スキャン結果を捨てる（編集中の上書き防止）
- 連続 3 回失敗で対応ループを停止し、エラー表示
- カメラ停止または `appMode` 切替で `clearInterval` でループ停止

## 保存リストと CSV のルール

- 「リストに保存」時に `companyUrl` を `https://` 始まりへ正規化
- 編集モードの「変更を保存」でも同じ正規化を適用
- 保存済みリストは React state のみで持つ。リロード / タブ閉じで消える
- `savedCards.length >= 1` のとき `beforeunload` リスナを張り、ブラウザの離脱確認ダイアログを出す
- CSV カラムは結果パネルの 12 フィールドと 1:1 対応。データが 0 件でも、空列のみのカラムでもヘッダーは常に出力

## レスポンシブ方針

- 最小幅 360px に対応
- 名刺モード: PC (md 以上) で video と結果パネルを横並び、それ未満では縦積み
- タップ領域は最低 44px（モバイルでの誤タップ回避）
- iOS Safari でモード切替タブのタップが妨げられないよう、`overflow-hidden` を親に使わず各ボタンに `rounded` を付ける

# Gemma4 画像認識Webアプリ - UI設計

## 画面構成（1画面）

```
┌──────────────────────────────────────────────┐
│  Gemma4 画像認識テスト                          │
├──────────────────────────────────────────────┤
│                                              │
│  [画像を選択]  [カメラ起動 / カメラ停止]          │
│                                              │
│  ┌──────────────────────────────────────┐   │
│  │                                      │   │
│  │   画像プレビュー / カメラ映像 (video)   │   │
│  │   (アップロード時はimgタグ表示)         │   │
│  │                                      │   │
│  └──────────────────────────────────────┘   │
│                                              │
│  [撮影して認識]  [認識する]                    │
│  ※カメラ起動中のみ「撮影して認識」を表示        │
│  ※画像選択時のみ「認識する」を表示             │
│                                              │
│  ステータス: 認識中... / エラーメッセージ        │
│                                              │
│  ─────────────── リアルタイム文字認識 ────────│
│  ┌──────────────────────────────────────┐   │
│  │ 認識された文字がここに表示されます       │   │
│  └──────────────────────────────────────┘   │
│  ※カメラ起動中のみ表示・動作               │
│                                              │
│  ─────────────── 画像認識結果 ───────────────│
│  ┌──────────────────────────────────────┐   │
│  │ Gemma4の回答がここに表示されます        │   │
│  └──────────────────────────────────────┘   │
│                                              │
└──────────────────────────────────────────────┘
```

## UI項目一覧

| 項目 | 種別 | 表示条件 | 説明 |
|---|---|---|---|
| 画像選択ボタン | `<input type="file">` | 常時 | JPEG/PNG画像を選択 |
| カメラ起動ボタン | `<button>` | カメラ未起動時 | カメラを起動する |
| カメラ停止ボタン | `<button>` | カメラ起動中 | カメラを停止する |
| プレビュー領域 | `<img>` or `<video>` | 画像選択後 / カメラ起動後 | 画像またはカメラ映像を表示 |
| 撮影して認識ボタン | `<button>` | カメラ起動中 | 現在のカメラ映像を静止画化して認識 |
| 認識するボタン | `<button>` | 画像選択後 | アップロード画像を認識 |
| ステータス表示 | `<p>` | 認識中 / エラー時 | 処理状態・エラー内容を表示 |
| リアルタイム文字認識欄 | `<div>` (スクロール可) | カメラ起動中 | 2秒ごとに更新されるOCR結果 |
| 画像認識結果欄 | `<div>` (スクロール可) | 認識完了後 | Gemma4の詳細な分析結果 |

## 状態管理 (React State)

| 状態名 | 型 | 初期値 | 説明 |
|---|---|---|---|
| `selectedImage` | `string \| null` | `null` | アップロード画像のbase64 |
| `cameraStream` | `MediaStream \| null` | `null` | カメラ映像ストリーム |
| `capturedImage` | `string \| null` | `null` | 撮影した静止画のbase64 |
| `analyzeResult` | `string` | `''` | 通常認識の結果テキスト |
| `realtimeText` | `string` | `''` | リアルタイムOCRの結果テキスト |
| `isAnalyzing` | `boolean` | `false` | 通常認識中フラグ |
| `isRealtimeOcrRunning` | `boolean` | `false` | OCRループ実行中フラグ |
| `errorMessage` | `string` | `''` | エラーメッセージ |

## ボタンの活性/非活性ルール

| ボタン | 非活性条件 |
|---|---|
| 認識するボタン | `selectedImage === null` または `isAnalyzing === true` |
| 撮影して認識ボタン | `cameraStream === null` または `isAnalyzing === true` |
| カメラ起動ボタン | `cameraStream !== null` |
| カメラ停止ボタン | `cameraStream === null` |

## リアルタイムOCRの表示ルール

- カメラ起動時にOCRループを開始する
- カメラ停止時にOCRループを停止する
- 前回と同じ文字列の場合は画面を更新しない（チラつき防止）
- 空文字が返ってきた場合は「文字が検出されていません」と表示する

## レスポンシブ方針

- 最小幅 360px に対応
- プレビュー領域は `max-width: 100%` で画面幅に追従
- モバイルではカメラ機能が主用途になるため、プレビューエリアを優先して上部配置

# Gemma4 画像認識Webアプリ - プロジェクト概要

## プロジェクト概要

Ollama上で動作するGemma4を使い、画像アップロードまたはカメラ撮影画像に対して画像認識・OCRを行う1画面構成のWebアプリケーション。

## 主要機能

| ID | 機能 | 内容 |
|---|---|---|
| F-01 | 画像アップロード | ローカル画像を選択して認識する |
| F-02 | カメラ起動 | ブラウザからカメラを起動する |
| F-03 | 撮影 | カメラ映像から静止画を取得する |
| F-04 | 画像認識 | 撮影画像またはアップロード画像をGemma4に送信する |
| F-05 | リアルタイム文字認識 | カメラ映像を2秒ごとにキャプチャし文字があれば表示する |
| F-06 | 認識結果表示 | 画像説明・抽出文字・補足情報を画面に表示する |
| F-07 | ローディング表示 | 認識中の状態を表示する |
| F-08 | エラー表示 | Ollama未起動・モデル未取得・カメラ拒否などを表示する |

## 技術スタック

| 区分 | 技術 |
|---|---|
| フロントエンド | Next.js (App Router) / React |
| バックエンド | Next.js Route Handler |
| LLM実行基盤 | Ollama (ローカル) |
| 使用モデル | gemma4 |
| カメラ制御 | MediaDevices API |
| 画像送信形式 | base64 |
| OCR/画像認識 | Gemma4 Vision |

## システム構成図

```
ユーザー
  │
  ▼
ブラウザ (React UI)
  │  画像アップロード / カメラ映像 / 定期フレーム
  │
  ▼
Next.js API Route
  │  base64画像 + プロンプト
  │
  ▼
Ollama (localhost:11434)
  │  POST /api/generate
  │
  ▼
gemma4 (Vision Model)
  │
  ▼
認識結果 → API → UI → ユーザー表示
```

## 実行環境・制約

- ローカルPC上で完結（外部APIへの画像送信なし）
- Ollamaが事前にインストール・起動済みであること
- gemma4モデルが `ollama pull gemma4` で取得済みであること
- ブラウザはChrome / Edge想定
- カメラ利用はHTTPS or localhost上でのみ動作

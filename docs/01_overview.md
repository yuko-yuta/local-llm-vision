# Local LLM Vision - プロジェクト概要

## プロジェクト概要

Ollama 上で動作する gemma4 を使い、カメラ映像 / アップロード画像に対して画像認識・OCR・名刺データ抽出を行う 1 画面構成の Web アプリケーション。

画面上部のタブで「通常認識」と「名刺読み取り」の 2 モードを切り替える。

## 主要機能

### 共通

| ID | 機能 | 内容 |
|---|---|---|
| F-01 | モード切替 | 「通常認識」「名刺読み取り」を画面上部のタブで切替 |
| F-02 | カメラ起動 / 停止 | ブラウザからカメラを起動・停止する |
| F-03 | 撮影（手動キャプチャ） | カメラ映像から静止画を取得して 1 回だけ認識を実行 |
| F-04 | ローディング表示 | 認識中の状態を表示する |
| F-05 | エラー表示 | Ollama 未起動・モデル未取得・カメラ拒否・連続エラーなどを表示する |

### 通常認識モード

| ID | 機能 | 内容 |
|---|---|---|
| F-10 | 画像認識（手動） | 撮影画像を gemma4 に送信し、構造化された分析結果を表示 |
| F-11 | リアルタイム文字認識 | カメラ映像を 2 秒ごとに OCR し、変化があれば表示を更新 |

### 名刺読み取りモード

| ID | 機能 | 内容 |
|---|---|---|
| F-20 | 自動スキャン | カメラ映像を 3 秒ごとにキャプチャし、名刺データ（12 項目）を抽出 |
| F-21 | 結果パネル編集 | 抽出された各値をその場で編集可能。編集中は自動スキャンを停止 |
| F-22 | リスト保存 | 編集済みデータを保存リストへ追加。会社URL は `https://` 始まりに正規化 |
| F-23 | 保存済み編集 | 保存済み行を後から編集可能（編集中は他の行の編集・削除を抑止） |
| F-24 | 保存済み削除 | 保存済み行を個別に削除 |
| F-25 | CSV ダウンロード | 全保存件を 12 カラムの CSV としてダウンロード（UTF-8 BOM + CRLF）。0 件でもヘッダーのみを出力 |
| F-26 | 離脱警告 | 保存件が 1 件以上ある状態で離脱しようとすると `beforeunload` 警告 |

### 抽出される名刺フィールド（12 項目）

`name` / `nameAlphabet` / `nameKana` / `company` / `department` / `title` / `companyUrl` / `address` / `email` / `tel` / `fax` / `mobile`

## 技術スタック

| 区分 | 技術 |
|---|---|
| フロントエンド | Next.js 16 (App Router) / React 19 |
| バックエンド | Next.js Route Handler |
| LLM 実行基盤 | Ollama (ローカル) |
| 使用モデル | gemma4 |
| カメラ制御 | MediaDevices API |
| 画像送信形式 | base64 (data URL) |
| OCR / 画像認識 / 名刺抽出 | Gemma4 Vision |
| スタイル | Tailwind CSS v4 |
| 状態管理 | React `useState` のみ（永続化なし） |

## システム構成図

```
ユーザー
  │
  ▼
ブラウザ (React UI)
  │  画像アップロード / カメラ映像 / 定期フレーム
  │
  ▼
Next.js API Route (/api/vision/{analyze,ocr,card})
  │  base64画像 + プロンプト
  │
  ▼
Ollama (localhost:11434)
  │  POST /api/chat (messages[].images で画像を渡す)
  │
  ▼
gemma4 (Vision Model)
  │
  ▼
認識結果 → API → UI → ユーザー表示
```

## 実行環境・制約

- ローカル PC 上で完結（外部 API への画像送信なし）
- Ollama が事前にインストール・起動済みであること
- gemma4 モデルが `ollama pull gemma4` で取得済みであること
- ブラウザは Chrome / Edge / Safari 想定（iOS Safari 17.3 以前は `AbortSignal.timeout` 不在のためフォールバック実装）
- カメラ利用は HTTPS or localhost 上でのみ動作
- 保存済み名刺データは **メモリ上にのみ保持** され、リロード・タブを閉じると失われる（CSV ダウンロードで永続化する想定）
